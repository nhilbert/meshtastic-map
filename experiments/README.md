# Experiments

Quick, throwaway explorations. Anything goes here; once something proves useful,
move it into `scripts/` (a reusable tool) or `src/meshplay/` (shared code).

Convention: one folder per experiment, prefixed with the date, e.g.

    experiments/2026-09-29-range-test/
        README.md      what you tried, what you found
        run.py         the code

Output (logs, CSVs, plots) goes to `data/`, which is not committed.

Start from `_template/` by copying it.
